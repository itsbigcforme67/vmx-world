# VMX World

The Xbox side of the VMX: a disc that downloads VMX games, installs them on the VMX (it is a memory unit to the
Xbox), plays them on the TV, shows news and score tables, and launches Xbox-side applets such as FOLD BUILDER.
Scores go in by phone, from the VMX itself.

- `docs/DESIGN.md`: the plan. `docs/STATUS.md`: where it is.
- `mockup/`: the TV screens in a browser (`world.html`), the score call (`modem.js`).
- `tools/`: `sync.sh` (copy game cores in), `modem_test.mjs` (the call through a fake phone line), `asset_png.py`.
